Hi, I'm **Daniel Servidie** — a software developer and technology enthusiast. I care about programming, electronics, and science, and I like taking on new challenges and learning along the way.

Right now I work at **TARMAC.IO** on financial applications with AWS (AppSync, API Gateway, Lambda, DynamoDB, RDS, Timestream, SQS, EC2, ECS), Node.js, React, and Nest.js. Before that I maintained and migrated .NET systems (ASP.NET, C#, VB, MSSQL) and built Node.js and React apps.

If I can put code on it, then I love it.
